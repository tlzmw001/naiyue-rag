## 1. 系统边界

本系统只描述一个合成业务。入口接收 request_id、route 和实验配置，输出基础分数与派生分数。
资料中的名字、日期、数值和规则均由助手构造，不代表照片中的真实业务。

## 2. 数据流

```text
请求 → 策略选择 → 预测原始结果 → 派生分计算 → 逐字段校准 → 输出
```

派生分计算使用预测原始值。基础字段经校准后的值不能倒流成为派生计算输入。
四条 route 只改变请求如何到达预测服务，计算与校准的规则相同。
本次任务加入联合策略，并为部分派生字段跳过校准；历史需求仍保留当时规则。
