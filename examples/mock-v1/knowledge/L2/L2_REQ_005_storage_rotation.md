# L2：本地归档轮换策略

> 文档ID：MOCK-NOISE-005
> 需求编号：MOCK-REQ-005
> 变更日期：2026-02-18
> 所属模块：归档存储
> 文档摘要：按文件总量和保留天数轮换归档；“策略”“原始”“合并”等词与目标任务重叠。
> 文档索引：§1 策略；§2 合并；§3 失败。

## 1. 轮换策略

归档策略根据保留天数判断过期，配置缺失则报告存储配置错误。
此处的“原始记录”表示磁盘归档，不是预测原始值。

## 2. 合并与覆盖

同一天的归档可以合并成一个目录；重复文件名使用存储编号区分。
此处“覆盖”描述文件归档，不表示实验 key 或输出头处理。

## 3. 失败记录

归档写入失败应报告 ARCHIVE_WRITE_FAILED，不能把旧归档缺失当查询无结果。
本材料不包含概率、价值、派生公式或实验策略的业务规则。
