> 文档索引：§1 背景；§2 拆分；§3 校验。

## 1. 需求背景

同一个对象可能命中两条实验策略，单条策略分别指定一个 output_head。

## 2. 拆分与覆盖

拆分开关关闭时，同 key 的历史单头策略只保留最后一条。
开关开启时，不同 key 的策略分别下发；同 key 仍只保留最后一条。
配置只包含一条策略时，拆分开关不改变输出。
覆盖依据是实验 key，不是模型名称。

## 3. 校验与异常

覆盖处理后，保留下来的策略不得声明重复的输出头。
例如 key_a 和 key_b 都声明 probability，则记录 DUPLICATE_HEAD，整次请求回退基线。
“同 key 的覆盖”与“不同 key 输出头重复”是两种路径，不能混为一条规则。
这一校验针对最终保留的输出头；未来联合策略也需明确是否沿用。
