# ADR0005：正式编码采用独立入口，取消实验接口兼容约束

日期：2026-10-12。状态：用户已确认设计；具体组件迁移尚未实施。

## 背景

当前load_settings面向旧A2快照，强制dataset/corpus_run/vector_run。公共包还导出Snapshot/Bootstrap/旧检索入口，间接加载experiments。直接沿用会使普通文档编码依赖无关路径和实验格式。

## 决策

用户明确：“独立入口，不必保留了，之前的都是实验，我们现在是做正式项目”。

- 正式M3使用EncodingSettings/load_encoding_settings，不要求旧快照字段。
- 复用严格配置校验、来源合同、向量验证和已核分词等实质能力；不为了维持实验API增加包装、兼容导出或旧查询回调适配。
- 正式查询编码交给新M5链路，不通过旧Snapshot间接接线。
- 按实际消费者迁移公共导出和上游配置耦合，同步调用、序列化及行为/异常测试；不机械重写所有已有功能。

## 后果与实施边界

此前“保留旧load_settings/快照签名”“提升校验后维持ProbeError兼容”“M3.4接旧embed_query”不再是正式建设要求，Spec0020已修订。

旧实验和负向结果作为对照资料；本次设计确认不执行目录删除、结果清空、依赖升级或真实配置修改。具体文件迁移/清理在对应切片核调用链并列明范围。取消兼容不能通过放宽断言或skip失败实现。
