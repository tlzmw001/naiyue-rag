# ADR0003：A1文件索引与证据预算策略

日期：2026-10-09。状态：用户“继续”已确认并完成Spec0005实验；本地文件/8000预算链路已验证，跨文档基线质量不足；不作为最终数据库/生产架构决定。

## 取舍

现有52公共单元，采用固定语义上下文＋正文作为Embedding输入，不额外拼入索引登记的随机/不透明标识、路径或版本hash；原文已有文档/需求编号、日期和Markdown链接原样保留，不能说字符串完全没有编号/路径。源位置/结构化ID/版本仍登记在索引和证据中。实测最长755字符/1442 UTF-8字节，逐条token数未知。

推荐JSON/JSONL持久化向量＋逐一原始cosine排序，实际加载后查询；不新增向量库依赖。参考Modular Chroma候选有存储/过滤能力，但其1-distance/2分数尺度与原始cosine不同；当前精确小规模基线更便于分清算法与框架差异。后续以规模/更新/性能证据重选，不预先许诺文件方案适合全库。

## 预算与后果

用户提出可放大字符上限，已授权扩大；助手据实际长度将本轮五组统一设为8000字符（不是用户逐字指定的数值）。每条证据包含排名/分数及完整Spec0004渲染；按候选前20相似度顺序装入，放不下记录并继续，不截断或用金标签优先选。索引/返回/评测标签分离；replay显式使用完整已验证向量缓存，零网络重放。

本轮只读格式测量：Q01全部必要渲染加连接5069字符；计划加检索前缀后5357。在历史4000下最多6/8，在当前8000下可容纳8/8，余2643字符；Q02为3443字符，可5/5；Q03为1905，可2/2。全52单元共27551字符、最长20条13406，8000仍约束返回。格式可容纳性不是模型检索结果；相似度顺序中噪声/背景仍可能挤掉必要证据，继续明确候选/预算遗漏。五组统一上限，旧4000结果不回写或直接混比。紧凑输出、多轮查询以后独立对照，未批准实施。

具体接口、资源、异常、标签及验收见[Spec0005](../specs/0005-a1-vector-baseline.md)。本轮只写规范/决策，不建索引、读Key或发模型请求。

## 实际后果

随后“继续”已实施：文件向量保存/重载、范围先过滤、原始cosine/top20、完整组装及源标签隔离通过工程验证；60新增/251总测试通过。实际5请求/56向量各2048维，7472输入tokens、估算0.003736元。无Key阻断网络重放排名/返回/指标一致。

Q01前20召回4/8，最终2/8；Q02为1/5→0/5；Q03全10返回、覆盖2/2但首名TC-05并非本题所需两条；Q04系统unknown。8000能容纳必要组合，但摘要/导航/说明等前列占据位置，不能由容量直接推断效果。未标注单元不自动当无关，不因此断言Embedding模型本身无效。保持这份基线，下一步同语料/表示/预算测试A2 BM25＋RRF；本轮没有调优输入/标签、增预算或重复模型请求。
