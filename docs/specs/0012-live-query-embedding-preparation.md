## 3. 契约草案

不改retrieve_once公开签名。拟新增适配器构造入口，接收非敏感配置和显式凭证，返回现有embed_query可调用对象；具体构造签名和配置字段在依赖准备后定稿，当前不预建工厂/空基类。

调用输入为query及当前索引identity(endpoint/model/dimensions/policy_id)。输出沿已实现schema：query_sha256、embedding_identity、vector、source_kind及可选usage。服务响应声明source_kind=service不独自证明真实HTTP，验证须另有实际请求计数/终态。

SDKbase_url与当前完整embedding endpoint的映射显式定义；不能只改模型名就切换旧索引。维度请求参数是否发送按服务能力明确配置，不照搬参考对text-embedding-3前缀的判断来猜智谱行为。向量个数、index排序、维度、有限性、零范数、返回model与usage沿现有校验复用。

凭证由本项目调用方显式提供，不读取Agent仓库配置/环境、不回写真实.env，不进配置序列化/日志/报告。SDK默认重试/环境读取行为先核源码，再显式控制；推荐首片max_retries=0，失败不切模型或伪装空证据。

## 4. 正常、异常与时间边界

正常：校验请求/授权及资源→按已绑定模型生成一条query向量→安全规范化→现有向量校验→检索/融合/证据。

非法请求或越权：在模型调用前拒绝，适配器调用数0。超限输入/错误身份/无Key在请求前失败。HTTP超时/认证/限流/服务故障、错误JSON/schema/维度/NaN/零向量明确失败，安全诊断不保存供应商原文、凭证或敏感输入。

请求timeout不冒称整个流程硬截止。首个真实验证须在可终止的外层监督下设置整体deadline及请求上限；仅公开/合成输入，模型、次数、预算及凭证可用性在执行前落实。不推定此前临时Key现在仍有效，也不将旧实验“预算不用考虑”无限迁移。
