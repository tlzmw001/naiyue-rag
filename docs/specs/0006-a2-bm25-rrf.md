## 4. 固定分词与BM25契约

tokenizer_policy=`zh-search-ascii-ident-v1`：按原顺序匹配ASCII段`[A-Za-z0-9_]+(?:-[A-Za-z0-9_]+)*`或基本汉字段`[\u4e00-\u9fff]+`。ASCII段整体lower，不把pv_short_raw、TC-02拆散；纯数字保留，小数/日期按此规则自然分段。汉字段使用独立jieba.Tokenizer的lcut_for_search(HMM=False)，去空白/纯标点，保留单字及搜索模式重叠词项。无停用词、自定义词典、词长/关键词数量限制或gold定制。语料保留重复词频；查询按出现顺序去重，每词只贡献一次。

同规则用于所有单元与原query，分词结果均保存以便失败分析。基本汉字范围之外的文字不在本轮支持范围，不能称通用多语分词。模型输入表示不变；分词是A2的新表示策略。

独立Tokenizer只使用安装包默认词典，记录词典内容hash、版本/策略。tmp_dir设为本次输出目录下新建jieba-cache，不复用系统临时缓存或旧运行缓存；加载/写入失败必须记录并使实验失败，不能在无可验证词典状态下标complete。

每个唯一(scope_ids,exclude_ids)先用现有validate_scope验证，再生成有序范围内pool，按unit_id排序作矩阵行映射。BM25词频/df/N/avgdl只从此pool计算，不在全库评分后过滤；全局范围为52单元，Q03仅10。空pool直接empty；非空pool中单元没有可用词项则明确tokenization_error，不静默删单元改变ID映射。

配置显式由CLI提供：k1=1.5，b=.75，method=idf_method=lucene，backend=csc_backend=numpy，dtype=float64，int_dtype=int32，auto_compile=False；index/save/load均show_progress=False，保存/加载allow_pickle=False，不传包含正文的corpus给第三方存储。

实施源码/数组核验：bm25s.scoring._np_csc_python固定indptr为int64；int_dtype=int32适用于词项/行索引，不代表列偏移也是int32。适配校验遵循原生data=float64、indices=int32、indptr=int64，不转换库数组或放宽测试。BM25前缀用`[bm25 ... bm25=...]`（科学计数＋填充）满足36字符，同A1开销不变。

实际BM25S公式为sum[log(1+(N-df+.5)/(df+.5))*tf/(tf+k1*(1-b+b*dl/avgdl))]，其TF分子没有(k1+1)。与常见带该固定因子的公式分数不同；同k1下只是统一正倍数，排序相同，不拿raw分数跨实现比较或当概率。

保存包原生5文件（3个CSC .npy＋vocab.index.json＋params.index.json）及本项目manifest/mapping/tokens。manifest包括schema_version=1、scope/exclude、pool单元ID有序表、各input_sha256、corpus_fingerprint、配置、package/dictionary身份、每文件hash、N/avgdl/vocab_count与complete标记。只读重载先核对身份/范围/hash/参数，验证矩阵维度、有限非负data、indptr/indices合法与num_docs映射；缺/坏/部分文件拒绝，不自动重建为成功。索引路径仅采用本项目生成的scope hash与固定文件名，manifest不能提供任意加载路径。

查询分词空或全部不在vocab时直接返回BM25空列表，不调用空get_scores，不把0分所有文档当命中。其余查询调用get_scores，在范围内按实际词项交集选择匹配单元，验证分数有限/正，按(-score,unit_id)取前20。索引/词典错误是error，只有正常无词命中可报告empty。保存重载前后每题分数/ID/排名一致。

## 5. RRF与返回契约

两路前20最多40个唯一unit_id。rrf_k=60、等权，rank从1开始；单元融合分数为它在每路的1/(60+rank)贡献之和，只出现一路也保留。输入每路必须ID唯一、rank连续且正文与公共单元匹配；重复ID或伪造位置报invalid_candidates，不双计贡献。融合以(-rrf_score,unit_id)排序取前20，不加角色偏好、召回权重或原始分数。

例：A在向量第5、关键词第2，分数1/65+1/62≈.03151；B只在向量第1，分数1/61≈.01639。A会排在B前面，这是两路共同靠前的排序偏好，不证明A业务更正确。

A2候选保留公共单元所有来源/版本/body/context字段，添加retrieval_method=hybrid、score_kind=rrf、score/rank及retrieval_info（dense_rank/cosine、sparse_rank/bm25_score、各路contribution；缺路字段为null）。BM25诊断候选method=sparse、score_kind=bm25。A1候选字段/默认格式不变。

沿用pack_evidence(candidates,max_context_chars)原签名，最小扩展内部前缀选择；原vector前缀逐字保持，hybrid标rrf、sparse标bm25，未知method/kind拒绝。三种前缀均ASCII固定36字符（含末尾换行，不足在换行前补空格，拒绝长度溢出）；BM25使用固定科学计数显示。保持同样36字符信息开销，避免格式长短导致预算对照失真。完整原rendered_text不变，条间2换行；按排名放不下则记录并继续，完整单元去重，不按gold选取或截断。

排名/原始分数/贡献完整字段保存在实验JSON，不全部拼入交给上层的context_text；预算计量与A1相同。记录各路前20、union、融合前20、selected及budget_excluded，可区分关键词未召回、union已命中但融合出前20、融合已命中但预算排除。answerability始终unknown，Q04不由负标签制造无答案识别。
